# MediConnect 🏥

**A Full-Stack Medical Practice Management Platform**

MediConnect is a web-based medical practice management application developed as my Bachelor's Final-Year Project (PFE) during my internship at **Creo Digitale**.

The platform aims to simplify communication and administrative tasks between patients, doctors, and medical practice administrators by bringing essential healthcare management services together in one application.

## 🎯 Project Objectives

The main objective of MediConnect is to provide a centralized platform for managing medical practices, organizing appointments, and improving communication between healthcare professionals and patients.

## ✨ Main Features

- **User Authentication:** Registration, login, logout, and profile management.
- **User Management:** Different roles and interfaces for patients, doctors, administrators, and super administrators.
- **Medical Practice Management:** Create, update, delete, and manage medical establishments.
- **Doctor Management:** Manage doctor profiles, specialties, and professional information.
- **Schedule Management:** Configure doctors' schedules, availability, and calendar events.
- **Appointment Management:** Book, view, update, and cancel medical appointments.
- **Patient Records:** Manage and access patient medical records.
- **Messaging System:** Enable communication between patients, doctors, and administrators.
- **Notifications:** Support appointment reminders and new-message notifications.

## ⚙️ Development Approach

The project was organized using the **Agile Scrum methodology**, with development tasks divided into five main sprints:

1. Authentication and profile management.
2. Medical establishment management.
3. Doctor schedules and event management.
4. Patient records and appointment management.
5. Messaging and communication.

The development process involved designing user interfaces, implementing backend APIs, connecting the database, testing API endpoints, and documenting the application.
